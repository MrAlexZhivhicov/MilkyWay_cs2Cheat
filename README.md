# Milky Way

Многофункциональный чит для CS2 с широкими возможностями кастомизации и интуитивным управлением.

## Запуск

1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите CS2
3. Запустите `python main.py`

## Структура проекта

- `main.py` — главный загрузчик проекта
- `configs/` — папка с именованными CFG-профилями для быстрого переключения настроек
- `logs/` — хранение журналов работы для отладки и анализа
- `scripts/` — директория для дополнительных модулей и расширений

## Управление

- `F1` — показать/скрыть панель управления
- `F2` — включить/выключить все функции одним нажатием

## Возможности

Проект разделён на три ключевых модуля:

### AIM
- **Vector Aim Bot** — точное прицеливание с гибкими настройками (FOV, сглаживание, приоритет целей и другое)
- **Trigger Bot** — автоматический выстрел при наведении на противника
- **Auto Shoot** — автоматическая стрельба при появлении цели в прицеле

### VISUAL (ESP)
- **Glow** — подсветка врагов через стены
- **Box ESP** — контурные рамки вокруг игроков
- **Health Bar** — отображение здоровья противников
- **Name ESP** — имена игроков над головами
- **Weapon ESP** — отображение оружия противников

### MISC
- **Radar Hack** — отображение всех игроков на радаре
- **Bunny Hop (BHop)** — автоматические прыжки для сохранения скорости
- **Config System** — сохранение и загрузка пользовательских профилей настроек
